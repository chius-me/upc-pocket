# 账号与偏好数据契约（Account & Preferences Contract）

双端使用独立语言实现本契约，语义与边界条件必须保持 100% 一致。

## 1. `CampusPreference`（常用校区）

| 枚举值 | 标识字符串 | 显示名称 | 说明 |
| --- | --- | --- | --- |
| `ALL` | `all` | 全部校区 | 默认值，展示两校区所有服务 |
| `TANGDAOWAN` | `tangdaowan` | 唐岛湾 | 优先显示唐岛湾相关服务与筛选项 |
| `GUZHENKOU` | `guzhenkou` | 古镇口 | 优先显示古镇口相关服务与筛选项 |

## 2. `ThemePreference`（外观主题）

| 枚举值 | 标识字符串 | 显示名称 | 说明 |
| --- | --- | --- | --- |
| `SYSTEM` | `system` | 跟随系统 | 默认值 |
| `LIGHT` | `light` | 浅色模式 | 强制浅色 |
| `DARK` | `dark` | 深色模式 | 强制深色 |

Android 端额外提供 `dynamicColorEnabled: Boolean = true`（Android 12+ Material You 动态取色开关）。

## 3. `StudentIdValidator`（学号格式校验）

校园卡余额等业务仅接受整串符合 UPC 学号规则的登录名；不截取子串、不自动更改大小写。

### 有效规则（精确匹配，区分大小写）

1. **纯 ASCII 数字**：长度 `8..16` 位，全部字符在 `'0'..'9'`。
2. **`S` / `Z` / `M` 前缀**（专业/学术硕士等格式）：总长 `9` 位，首字符为 `'S'`、`'Z'` 或 `'M'`（大写），后 `8` 位为 ASCII 数字 `'0'..'9'`。
3. **`TS` 前缀**（工程/同等学力等格式）：总长 `11` 位，前缀 `"TS"`（大写），后 `9` 位为 ASCII 数字 `'0'..'9'`。
4. **`BY` 前缀**（博士等格式）：总长 `12` 位，前缀 `"BY"`（大写），后 `10` 位为 ASCII 数字 `'0'..'9'`。

### 双端共享测试向量

| 输入 | 期望结果 | 原因 |
| --- | --- | --- |
| `"2024010101"` | `true` | 10 位数字（8–16 范围内） |
| `"12345678"` | `true` | 最短 8 位数字 |
| `"1234567890123456"` | `true` | 最长 16 位数字 |
| `"S24010001"` | `true` | `S` + 8 位数字 |
| `"Z24010001"` | `true` | `Z` + 8 位数字 |
| `"M24010001"` | `true` | `M` + 8 位数字 |
| `"TS240100001"` | `true` | `TS` + 9 位数字 |
| `"BY2401000001"` | `true` | `BY` + 10 位数字 |
| `"1234567"` | `false` | 少于 8 位 |
| `"12345678901234567"` | `false` | 超过 16 位 |
| `"s24010001"` | `false` | 小写前缀不自动转换 |
| `"ts240100001"` | `false` | 小写前缀无效 |
| `"by2401000001"` | `false` | 小写前缀无效 |
| `"S2401000"` | `false` | `S` 后不足 8 位 |
| `"TS24010000"` | `false` | `TS` 后不足 9 位 |
| `"BY240100000"` | `false` | `BY` 后不足 10 位 |
| `"TS240100001X"` | `false` | 含非数字后缀 |
| `" 2024010101 "` | `false` | 未 trim 的空白不允许通过原始校验（保存时按规则统一 trim 后再判） |
| `"٢٠٢٤٠١٠١"` | `false` | 非 ASCII 阿拉伯数字 |

## 4. `SchoolAccountState`（账号状态模型）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `status` | `AccountStatus` | `UNSET`（未配置）/ `SAVED_UNVERIFIED`（已保存未验证）/ `RECOVERY_REQUIRED`（需要重新保存） |
| `generation` | `Int64` / `Long` | 从 `0` 起单调递增，每次保存/改密/换号/删除 `+1` |
| `accountId` | `String?` | 对规范化登录名计算 SHA-256 的十六进制摘要前缀（16 字符），用于标识个人缓存归属，不包含原登录名 |
| `maskedLoginName` | `String?` | 脱敏登录名（如首 2 位 + `***` + 末 2 位，短串全部掩码），绝不含密码 |
| `isValidStudentId` | `Boolean` / `Bool` | 当前保存登录名是否满足 `StudentIdValidator`（可作为后续校园卡余额本人学号依据） |
| `savedAtEpochMillis` | `Int64?` / `Long?` | 保存时间戳（毫秒） |

### 账号操作语义

- **首次保存**：`generation` 变为 `source + 1`，状态转为 `SAVED_UNVERIFIED`。
- **同账号改密**：`accountId` 保持不变，`generation` 递增，调用方据此使旧认证会话失效。
- **更换账号**：`accountId` 变更，`generation` 递增，清除旧账号关联会话与缓存。
- **删除账号**：清除密文与元数据，`accountId = nil/null`，`generation` 保持或递增后归入 `UNSET`。
- **密文损坏 / 密钥失效**：自动清理不可读元数据并发布 `RECOVERY_REQUIRED`，不崩溃、不保留明文。
